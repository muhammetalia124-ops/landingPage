01 BACKEND / FULL-STACK

IntegrationHub — Monolitik REST API

C# ile geliştirilmiş, JWT ile oturum doğrulayan ve katmanlı mimariye sahip monolitik bir REST API. İsteği seçilen hizmete göre ilgili servise yönlendirir, sonuçları kullanıcıya döndürür ve başarılı işlemleri geçmişe kaydeder; kullanıcılar seçtikleri hizmet üzerinden sorgulama ve hesaplama yapabilir.

Proje ne yapıyor?

IntegrationHub, kullanıcıların hesap oluşturup e-posta ve şifreyle giriş yaptığı; giriş sonrası seçtiği hizmete göre sorgulama ve hesaplama yapabildiği bir web uygulamasıdır. Backend tarafı ASP.NET Core Web API ile geliştirildi.

Backend nasıl çalışıyor?

API, JWT ile oturum doğrular; seçilen hizmete göre isteği ilgili servise yönlendirir, sonuçları kullanıcıya döndürür ve başarılı işlemleri kullanıcının geçmişine kaydeder. Backend API, Application, Domain ve Infrastructure katmanlarına ayrılmıştır.

Yetkilendirme ve yönetim

Kullanıcılar geçmiş işlemlerini görüntüleyebilir. Yönetici kullanıcıları listeleyip ekleyebilir, düzenleyebilir, devre dışı bırakabilir, şifrelerini değiştirebilir ve işlem geçmişlerini yönetebilir.

Veri yapısı

SQL Server üzerinde kullanıcı hesapları, kullanıcı işlem geçmişi ve harici servis önbellekleri ayrı veritabanlarında tutulur; böylece önbellek verileri kullanıcı geçmişinden ayrı kalır.
